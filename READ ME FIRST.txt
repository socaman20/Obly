STAR CITIZEN VOICE CONTROL
Made by Obly.  Free to use, free to pass on.


WHAT IT IS
----------
You hold a button, say what you want, and it presses the key for you.
"Landing gear."  "Power to shields."  "Set route to Lorville."

It listens on your own PC. Nothing you say leaves this machine -- no account,
no server, no sign-up. Once you have the folder it works with the internet
off.


INSTALL
-------
Extract the whole folder somewhere -- your Desktop is fine -- then run

    INSTALL.bat

It makes a desktop shortcut and starts the program. That is the entire
install: nothing goes into Program Files, nothing is written to the Windows
registry. To uninstall, delete the folder.

If you would rather skip that, double-click StarCitizenVoiceControl.exe.

One thing that catches people: if you run INSTALL.bat straight out of the zip
without extracting, Windows is showing you a preview and the program is not
really there. Extract first.


FIRST FIVE MINUTES
------------------
1. Press START LISTENING. The first press takes a few seconds while the
   recogniser loads. After that it is instant.

2. Talk. The bar next to the buttons should move. If it does not, Windows is
   not hearing your microphone -- fix that first, it is not the program.

3. With Star Citizen in front of you, hold RIGHT CTRL and say "landing gear".

4. Read HOW TO in the sidebar. It has a button that reads YOUR OWN Star
   Citizen keybinds and tells you which commands cannot work on your layout
   and why. That answers most "it did nothing" questions in one click.


TWO WAYS TO TALK TO IT
----------------------
PUSH TO TALK   Hold a key, a HOTAS button or a gamepad button. All three work
               at once, so use whichever is under your hand. Set a stick
               button on the Listen page -- press the button and it learns it.

OPEN MIC       No button at all. Set a wake word so only speech that starts
               with it counts; otherwise every sentence in the room is a
               candidate, including whatever is coming out of Discord.

Either way nothing fires unless Star Citizen is the window in front, so a
chat with your org cannot scuttle your ship.


PLOTTING A ROUTE BY VOICE
-------------------------
    "open map"                  opens the starmap
    "set route to Lorville"     clicks the search box, types it, presses
                                Enter, and stops so you can look
    "set GPS"                   confirms it
    "close map"                 done

It corrects what it hears against every place in the game before typing, so
"laura ville" becomes Lorville and "new beverage" becomes New Babbage. If you
name somewhere that is not in the current build it tells you instead of
typing a name the game has never heard of.


WHEN A COMMAND DOES NOTHING
---------------------------
Almost always this is the game's keybind, not the program. Star Citizen lets
you clear a binding or move it to a joystick, and a cleared binding has no key
for anything to send. HOW TO -> "Read my keybinds" will tell you exactly which
ones and why. It only looks; it changes nothing.


KEEPING IT CURRENT
------------------
Ship and commodity prices come from live community data. MARKET -> "Update
prices" fetches the latest. If a service is down it falls back to the last
good copy rather than showing you nothing.


WHAT IS IN THE SIDEBAR
----------------------
Listen        the microphone, the transcript, and what was sent to the game
Commands      all 52, with an on/off switch and the key each one sends
My Commands   anything you add yourself, kept safe from updates
Starmap       every system, moon and landing zone -- and where you are
Routes        your plotted routes; the game forgets these, this does not
Market        ship and commodity prices
Settings      push-to-talk, control scheme, safety
How To        the rest


A FAIR WARNING
--------------
Star Citizen changes keybinds every patch, so some of these will be wrong at
some point. Do not try a brand new command on a ship or a cargo run you would
be upset to lose. Try it parked.
