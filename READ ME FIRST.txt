STAR CITIZEN VOICE CONTROL
Made by Obly.  Free to use, free to pass on.


WINDOWS 10 OR 11 ONLY
---------------------
Not Mac, not Linux. Star Citizen is a Windows game -- there is no Mac version
at all -- and this program sends keystrokes into it, reads your HOTAS, and
reads your keybinds out of the game's own files. All of that is Windows.

The file in this folder is a Windows program. On a Mac it will not open.


WHAT IT IS
----------
You hold a button, say what you want, and it presses the key for you.
"Landing gear."  "Power to shields."  "Set route to Lorville."

It listens on your own PC. Nothing you say leaves this machine -- no account,
no server, no sign-up. Once you have the folder it works with the internet
off.


INSTALL
-------
1. Right-click the zip and choose "Extract All". Your Desktop is fine.
2. Open the folder that appears.
3. Double-click     START HERE

That is the entire install: nothing goes into Program Files, nothing is
written to the Windows registry. To uninstall, delete the folder.

It checks for one Microsoft component called WebView2 -- the thing that draws
this program's window. Windows 11 has it built in; Windows 10 often does not.
If it is missing you get one question, it installs itself, and carries on.
Microsoft's installer is in this folder, so it works even on a machine where
that download would have been blocked.


"THERE IS NO .EXE IN HERE"
--------------------------
There is -- Windows is hiding it from you. Windows hides file extensions by
default, so the program shows up as

    StarCitizenVoiceControl        (with a ship icon)

and not "StarCitizenVoiceControl.exe". Same file. Double-click it and it runs.

If there is genuinely no such file, one of two things happened:

  YOU RAN IT FROM INSIDE THE ZIP. Windows shows the inside of a zip as if it
  were a folder, but the files are not on your disk yet. Extract first.

  YOUR ANTIVIRUS DELETED IT. This program is not code-signed -- a certificate
  costs a few hundred a year and this is free -- and it types on your keyboard
  for you, which is precisely the behaviour antivirus software looks for.
  Some remove it without asking. Check your quarantine, restore it, and allow
  the folder.

The first time you run it, Windows may say "Windows protected your PC". That
appears for every unsigned program. Click "More info", then "Run anyway".


FIRST FIVE MINUTES
------------------
1. Press START LISTENING. The first press takes a few seconds while the
   recogniser loads. After that it is instant.

2. Talk. The bar next to the buttons should move. If it does not, Windows is
   not hearing your microphone -- fix that first, it is not the program.

3. With Star Citizen in front of you, hold RIGHT CTRL and say "landing gear".

4. Read HOW TO in the sidebar. It has a button that reads YOUR OWN Star
   Citizen keybinds and tells you which commands cannot work on your layout
   and why. That answers most "it did nothing" questions in one click.


TWO WAYS TO TALK TO IT
----------------------
PUSH TO TALK   Hold a key, a HOTAS button or a gamepad button. All three work
               at once, so use whichever is under your hand. Set a stick
               button on the Listen page -- press the button and it learns it.

OPEN MIC       No button at all. Set a wake word so only speech that starts
               with it counts; otherwise every sentence in the room is a
               candidate, including whatever is coming out of Discord.

Either way nothing fires unless Star Citizen is the window in front, so a
chat with your org cannot scuttle your ship.


PLOTTING A ROUTE BY VOICE
-------------------------
    "open map"                  opens the starmap
    "set route to Lorville"     clicks the search box, types it, presses
                                Enter, and stops so you can look
    "set GPS"                   confirms it
    "close map"                 done

It corrects what it hears against every place in the game before typing, so
"laura ville" becomes Lorville and "new beverage" becomes New Babbage. If you
name somewhere that is not in the current build it tells you instead of
typing a name the game has never heard of.


WHEN A COMMAND DOES NOTHING
---------------------------
Almost always this is the game's keybind, not the program. Star Citizen lets
you clear a binding or move it to a joystick, and a cleared binding has no key
for anything to send. HOW TO -> "Read my keybinds" will tell you exactly which
ones and why. It only looks; it changes nothing.


KEEPING IT CURRENT
------------------
Ship and commodity prices come from live community data. MARKET -> "Update
prices" fetches the latest. If a service is down it falls back to the last
good copy rather than showing you nothing.


WHERE EVERYTHING GOES
---------------------
Nothing is installed. The program runs from the folder you extracted, puts
nothing in Program Files and nothing in the Windows registry. Move that folder
wherever you like -- Desktop, a games drive, a USB stick -- and it still works.
To uninstall, delete the folder.

Two places, and it matters which is which:

  THE FOLDER YOU EXTRACTED
      The program and everything it ships with. A new version replaces this
      whole folder, so keep nothing of your own in here.

  YOUR OWN FILES
      C:\Users\<you>\AppData\Local\Star Citizen Voice Control

      my_commands.json    commands you wrote, and any you switched off
      my_routes.json      every destination you plotted
      prices\             cached ship and commodity prices
      window\             the window's own cache

      A new version never touches this folder, so your commands and your route
      history survive an update. Copy this folder to carry yourself to another
      PC. Delete it to start completely fresh.

AppData is hidden by default, so you cannot browse to it -- paste that path
into the address bar of any Explorer window. Or open the program and use
HOW TO -> "Open my folder", which does it for you.

Two files appear next to the program when something goes wrong:

  voice-control.log      what happened
  selftest-result.txt    what is missing (run START HERE to produce it)

If you report a problem, those two are what to send.


WHAT IS IN THE SIDEBAR
----------------------
Listen        the microphone, the transcript, and what was sent to the game
Commands      all 52, with an on/off switch and the key each one sends
My Commands   anything you add yourself, kept safe from updates
Starmap       every system, moon and landing zone -- and where you are
Routes        your plotted routes; the game forgets these, this does not
Market        ship and commodity prices
Settings      push-to-talk, control scheme, safety
How To        the rest


A FAIR WARNING
--------------
Star Citizen changes keybinds every patch, so some of these will be wrong at
some point. Do not try a brand new command on a ship or a cargo run you would
be upset to lose. Try it parked.
